# Digital Logic Design Project

This is a group project for the Digital Logic Design course.

The project contains two combinational logic system designs:

1. Access Control & Indicators
2. Mini Vending Controller

The systems were designed using:
- Truth Tables
- Karnaugh Maps (K-Maps)
- SOP Minimization
- CircuitVerse Simulation
